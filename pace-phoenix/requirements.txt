# ENV 2 -- "grn39"  (python 3.9)  *** Arboreto GRNBoost2 ***
#
# WHY THESE OLD PINS
#   arboreto 0.1.6 is incompatible with modern numpy/dask. It is built on the
#   scikit-learn GradientBoostingRegressor API and dask.distributed's
#   pre-2022 internals, so it needs the 2021 stack.
#
#   click==8.0.4 is REQUIRED, not cosmetic:
#     distributed 2021.10 imports `click._unicodefun`, which click 8.1 removed.
#     With click >= 8.1 the `dask-worker` / `dask-scheduler` CLI entry points die
#     with `ImportError: cannot import name '_unicodefun' from 'click'`.
#     In-process LocalCluster still works, so the failure is easy to miss -- it
#     only bites when you use a standalone scheduler or dask-jobqueue, i.e.
#     exactly the multi-node GRN mode. Verified: click 8.0.4 ships _unicodefun.
#
#   (The macOS development env used click 8.1.8 and got away with it because the
#   published runs used LocalCluster only. Do not copy that pin.)
#
#   install: conda create -n grn39 -c conda-forge python=3.9 numpy=1.21 \
#              pandas=1.4 scipy=1.9 scikit-learn=1.1 dask=2021.10 \
#              distributed=2021.10 click=8.0.4 joblib pip
#            pip install arboreto==0.1.6 dask-jobqueue==0.7.2
